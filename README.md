# Финансовый аналитик-агент

Интерактивный чат-ассистент на LangChain для работы с текущими рыночными данными акций. Источник данных — Yahoo Finance через `yfinance`, модель — `gpt-4o-mini`, подключаемая через ProxyAPI (`https://api.proxyapi.ru/v1`). Агент не даёт инвестиционных рекомендаций: он собирает факты и объясняет ограничения данных.

## Устройство приложения

| Файл | Назначение |
| --- | --- |
| `config.py` | Настройки модели, ProxyAPI, таймаутов, лимитов и логирования; загрузка `.env`; проверка ключа. |
| `logging_config.py` | Настройка файлового и консольного логирования, маскировка ключей. |
| `tools.py` | Инструменты агента: `resolve_tickers`, `get_quotes`, `format_market_snapshot`. |
| `agent.py` | Сборка агента через `create_agent`, `init_chat_model`, `InMemorySaver` и system prompt. |
| `main.py` | Интерактивный REPL; команды `exit` и `new`. |
| `tests/test_tools.py` | Module-тесты инструментов с моками `yfinance`. |
| `tests/test_logging.py` | Тесты настройки логирования и маскировки ключа. |

### Инструменты

- **`resolve_tickers(queries, limit)`** — ищет компании через `yf.Search`, оставляет только `EQUITY`, возвращает `запрос -> SYMBOL`.
- **`get_quotes(tickers, fields)`** — получает цену, изменение за день, капитализацию, P/E и объём; поддерживает псевдонимы полей, валидирует тикеры, ограничивает вывод и явно помечает пропуски как «Нет данных».
- **`format_market_snapshot(...)`** — форматирует снимок по одному тикеру в читаемую строку.

### Маршрут агента

1. Пользователь задаёт вопрос.
2. При необходимости вызывается `resolve_tickers`.
3. Вызывается `get_quotes` с нужными полями.
4. Для одного тикера дополнительно используется `format_market_snapshot`.
5. Ответ формируется блоками **Данные / Краткий вывод / Ограничения анализа**.

Все числа берутся только из инструментов. В блоке ограничений указываются источник Yahoo Finance, возможная задержка котировок, trailing P/E и отсутствие инвестиционной рекомендации.

## Установка и запуск

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните PROXYAPI_API_KEY в .env
python main.py
```

Модель OpenAI подключается через OpenAI-совместимый endpoint ProxyAPI. Адрес задаётся в `PROXYAPI_BASE_URL`, ключ — в `PROXYAPI_API_KEY` (для совместимости также поддерживается `OPENAI_API_KEY`).

## Логирование

Логи пишутся в `logs/app.log` (путь и имя меняются через `LOG_DIR` / `LOG_FILE`). Файл ротируется при достижении `LOG_MAX_BYTES`, хранится `LOG_BACKUP_COUNT` старых файлов. Уровень файлового лога — `LOG_LEVEL`, консоли — `LOG_CONSOLE_LEVEL` (по умолчанию в консоль попадают только `WARNING` и выше).

В лог записываются запуск, сборка агента, вызовы tools, ошибки и результат обработки запроса. Ключ API маскируется. По умолчанию текст вопроса пользователя не пишется — только его длина; чтобы логировать текст, установите `LOG_USER_MESSAGES=true`.

Пример запроса:

```text
You> Сравни Apple и Microsoft по цене, капитализации и P/E
```

Проверки:

```bash
python -m unittest discover -s tests -v
python -m compileall -q .
```
